# Arogya Aadhar

## Description
A mobile-first healthcare awareness platform designed to provide information about government healthcare schemes and help users identify and report healthcare-related scams.

## Features
- Government healthcare scheme information
- Interactive scheme guidance
- Healthcare scam awareness
- Scam detection and reporting
- Community-based scam reporting
- Responsive and user-friendly interface

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Other:** n8n, VLM/AI
